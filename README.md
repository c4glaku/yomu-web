# Yomu Web

A simple React companion to the Yomu SwiftUI Japanese reading app. Books and learning progress stay in this browser; no account, API key, or application server is needed.

## Development

```sh
npm install
npm run dev
```

## Implementation milestones

1. Initialize the standalone React repository and GitHub remote.
2. Add the persistent library, book imports, and reading experience.
3. Add dictionary lookup, vocabulary, quizzes, activity, and settings.
4. Verify the application and document the browser version's boundaries.

The Swift source lives in the neighboring `JapeneseApp` directory. This project has its own Git history.
